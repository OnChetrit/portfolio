# Portfolio

A personal front-end developer portfolio showcasing projects, animation work, and technical skills.

**Live site:** [onchetrit.github.io/portfolio](https://onchetrit.github.io/portfolio/)

## Tech

React, GSAP, Framer Motion, Fullpage.js, Sass, and Create React App.

## Run locally

~~~bash
npm install
npm start
~~~

Open http://localhost:3000.

## Available scripts

~~~bash
npm start
npm test
npm run build
~~~
